## Libreria de lista, pila y cola
Esta libreria la usé para la materia Algoritmos y Estructuras de Datos (AyED)

Listas: Similar a un array pero no igual. El tamaño de las listas es variable, puede crecer en tiempo de ejecucion y en la memoria no se almacenan todos los nodos contiguos, como en el array que es de tamaño fijo y si almacenan todos los elementos contiguos. 
En las listas se puede insertar, obtener y remover un elemento en cualquiera de las posiciones, tambien se pueden ordenar.
Existen las listas de tipo: Simplemente enlazada, doblemente enlazada y circular. 



Pilas - LIFO: Es una lista de tipo LIFO, las pilas son listas pero con funcionalidades restringidas. En las pilas solo se permite insertar y eliminar elementos desde la cima (apilar y desapilar). No se pueden recorrer como las listas.

Cola - FIFO: Es una lista de tipo FIFO, las colas son listas pero con funcionalidades restringidas. En las colas solo se permite insertar elementos por el final (encolar) y eliminar elementos por el frente (desencolar).No se pueden recorrer

Nodo: Es una estructura que contiene el dato a almacenar y un puntero al siguiente nodo, permitiendo enlazar elementos de forma dinamica en memoria sin necesidad de que sean contiguos.
